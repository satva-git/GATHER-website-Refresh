TECHNICAL IMPLEMENTATION
================================================================================

JAVASCRIPT CHANGES:

Old Problematic Pattern:
  const visuallyOpen = item.classList.contains('open') ||
    (!item.classList.contains('is-closing') && getComputedStyle(menu).visibility !== 'hidden');
  closeNavDrops();
  if(visuallyOpen) {
    item.classList.add('is-closing');  // Confusing intermediate state
  }

New Clean Pattern:
  const isOpen = item.classList.contains('open');
  closeNavDrops();
  if(isOpen) {
    item.classList.remove('open');
  } else {
    item.classList.add('open');
  }

Added Features:
  - Escape key to close dropdown
  - Better link click detection
  - Capture-phase click outside detection
  - Focus management after close

CSS CHANGES:

Old Pattern (with hover interference):
  .nav-item--drop.open > .nav-drop,
  .nav-item--drop:hover:not(.is-closing) > .nav-drop,
  .nav-item--drop:focus-within:not(.is-closing) > .nav-drop {
    opacity: 1;
  }

New Clean Pattern:
  .nav-item--drop.open > .nav-drop {
    opacity: 1;
  }

Added Improvements:
  - Full-width mega menus with proper positioning
  - Responsive max-width constraints
  - Better border-radius consistency
  - Improved mega-menu-inner centering
